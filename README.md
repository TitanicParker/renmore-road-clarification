# Renmore Road Clarification

A GitHub Pages site requesting transparent geographic and procedural framing in reporting on the Renmore Road planning appeal.

## Purpose

This project documents concerns about:

- Geographic reframing of the development as a general “Lough Atalia area” issue.
- Abstraction of local residents most directly affected.
- The shift from a locally sustained refusal context to a more technical institutional framing.

## Deployment

This repository is intended to be deployed using GitHub Pages.

Settings -> Pages -> Deploy from a branch -> main -> /(root)
